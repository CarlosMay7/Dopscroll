# Screens

Capturas del juego a 1920×1080 (Godot, renderizado real) como referencia de cada pantalla.

- `lock-screen.png`: pantalla de bloqueo, el menú principal.
- `screen-time-and-prym.png`: el informe Screen Time junto a la tienda PRYM, con la confirmación de tocar pasto.
- `prym-snacks.png`: la pestaña Snacks con los consumibles de una noche.
- `settings-app.png`: la app de Ajustes.
- `album-app.png`: el Álbum (Mythics).
- `pause.png`: la pausa sobre la tienda.
- `desk-battery-tip.png`: el escritorio con el aviso de batería, el cable suelto y el chip BORED.
- `desk-charging-blur.png`: cargando (cable en eyes), ojos borrosos, aviso de borrosidad y fiebre.
